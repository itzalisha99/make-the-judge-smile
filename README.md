One line, at most 200 characters, about a small good thing that happened today — the warmest, most surprising line takes the $5.

## The line

> My neighbour left mangoes at my door today with a note that just said: eat, you look tired.

A neighbour's quiet kindness, with a blunt little note as the surprise: mangoes at the door, and a note that doesn't say "with love" — it says "eat, you look tired."

## How it works

`main.py` (Python standard library only, deterministic) writes the line to `/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
